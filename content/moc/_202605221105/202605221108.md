# CSharp Language Basics

## Abstraction

This collection covers the foundational elements of C# programming language, organized into logical categories:

### Project Setup
- **Console Project Creation**: Using `dotnet new console` CLI to initialize projects with either minimal top-level statements or traditional `Main` function structure

### Input/Output
- **Console Operations**: `WriteLine()` for line-by-line output, `Write()` for side-by-side output, `ReadKey()` for pausing execution, `Clear()` for screen clearing

### Data Types & Variables
- **Primitive Types**: Signed/unsigned integers (`sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`), floating-point (`float`, `double`, `decimal`), characters (`char`), booleans (`bool`), and strings (`string`)
- **Variable Declaration**: Syntax `dataType variableName = value;` for storing typed data

### Operators
- **Arithmetic**: `+`, `-`, `*`, `/`, `%` with precedence rules
- **Assignment**: Combined operators (`+=`, `-=`, `*=`, `/=`, `%=`)
- **Increment/Decrement**: Prefix vs postfix (`++`, `--`) behavior
- **Comparison**: `==`, `!=`, `<`, `>`, `<=`, `>=` returning boolean results
- **Logical**: `&`, `&&`, `|`, `||`, `!`, `^` with short-circuit evaluation
- **String**: Concatenation with `+`
- **Ternary**: Conditional expression `? :` for inline logic

### Control Flow

**Conditional Statements:**
- **if-else if-else**: Sequential condition evaluation with short-circuit behavior, ideal for range checks
- **switch**: Single-expression branching with `case` clauses and optional `default` fallback

**Loop Structures:**
- **for**: `for (initialization; condition; iterator)` with flexible initialization patterns
- **while**: Pre-condition check, executes zero or more times
- **do-while**: Post-condition check, guaranteed at least one execution

**Flow Control:**
- **break**: Immediately exits the nearest enclosing loop or switch
- **continue**: Skips remaining code in current iteration, advances to next iteration
- **goto**: Unconditional jump to labeled statements within the same method

These fundamentals provide the building blocks for writing C# programs, from simple console applications to more complex software systems.

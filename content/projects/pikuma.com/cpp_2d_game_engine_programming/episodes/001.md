## Learning Outcomes

- We will create a simple 2D `game engine` from scratch
- Learn the fundamentals of game engine `architecture` and game `design patterns`
- We will use modern `C++` with a set of small helper `libraries`
	- C++
	- GLM
	- SDL
	- Lua
	- IMGUI
- We will implement:
	- A simple 2D `rendering` system
	- A frame-rate independent `game loop`
	- An `asset` manager to handle textures, fonts and sound files
	- A minimal `Entity-Component-System`
	- An `Event system` to dispatch and listen to events
	- A `Logging` system to display information
	- `Collision` handling and 2D movement
	- Loading map information and `tiles`
	- Rendering `text` and other `GUI` elements
- Learn how to embed a `scripting language` with our game engine

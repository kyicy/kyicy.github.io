# 使用 .NET CLI 创建 C# 命令行项目

## 核心方法 (The Core) 
在终端中执行以下命令，可以快速初始化一个 C# 命令行（控制台）项目：

```sh
dotnet new console -o <Project_Name>
```

## 关键概念与细节 (Context & Details)

1. **顶级语句 (Top-level Statements)**：从 .NET 6 开始，默认模板极其精简。`Program.cs` 中不再显式包含 `class Program` 和 `static void Main`，直接编写业务逻辑即可。
2. **传统结构**：若需要生成带有传统 `Main` 函数入口的项目，需追加参数：
```sh
dotnet new console -o <Project_Name> --use-program-main
```
3. **快速运行**：进入目录后，使用 `dotnet run` 会自动执行编译并启动程序。

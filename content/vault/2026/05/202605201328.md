# Creating CSharp Console Projects with .NET CLI

## The Core
Execute the following command in the terminal to quickly initialize a CSharp console project:

```sh
dotnet new console -o <Project_Name>
```

## Context & Details

1. **Top-level Statements**: Starting with .NET 6, the default template is extremely minimal. `Program.cs` no longer explicitly includes `class Program` and `static void Main`; you can directly write business logic.
2. **Traditional Structure**: If you need to generate a project with the traditional `Main` function entry point, append the parameter:
```sh
dotnet new console -o <Project_Name> --use-program-main
```
3. **Quick Run**: After navigating into the directory, using `dotnet run` will automatically compile and start the program.

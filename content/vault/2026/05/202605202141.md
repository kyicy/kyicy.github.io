# CSharp Console Basic Input Output

## The Core

CSharp console operations are primarily handled through the `System.Console` class:

| Method | Purpose | Behavior |
|--------|---------|----------|
| `WriteLine()` | Print message with newline | Line-by-line output |
| `Write()` | Print message without newline | Side-by-side output |
| `ReadKey()` | Wait for key press | Pause program execution |
| `Clear()` | Clear screen | Clear console content |

## Context & Details

**Line-by-line output example:**
```csharp
System.Console.WriteLine("Welcome");
System.Console.WriteLine("to");
System.Console.WriteLine("CSharp Programming");
// Output:
// Welcome
// to
// CSharp Programming
```

**Side-by-side output example:**
```csharp
System.Console.Write("Welcome ");
System.Console.Write("to ");
System.Console.Write("CSharp Programming");
// Output: Welcome to CSharp Programming
```

**Complete example:**
```csharp
class Sample
{
    static void Main(string[] args)
    {
        // Print line-by-line
        System.Console.WriteLine("Welcome");
        System.Console.WriteLine("to");
        System.Console.WriteLine("CSharp Programming");

        // Print side-by-side
        System.Console.Write("Welcome ");
        System.Console.Write("to ");
        System.Console.Write("CSharp Programming");

        // Wait for key press
        System.Console.ReadKey();

        // Clear the screen
        System.Console.Clear();

        System.Console.WriteLine("Thank you.");
        System.Console.ReadKey();
    }
}
```

# CSharp Variable Declaration and Usage

## The Core

Variables in CSharp store data values and must be declared with a specific type:

| Type | Example | Description |
|------|---------|-------------|
| `string` | `string name = "John";` | Text/characters |
| `int` | `int age = 20;` | Whole numbers |
| `double` | `double price = 19.99;` | Decimal numbers |
| `bool` | `bool isValid = true;` | True/false values |

**Declaration Syntax:**
```csharp
dataType variableName = value;
```

## Context & Details

**Example:**
```csharp
class Sample
{
    static void Main(string[] args)
    {
        // Declare variables
        string studentName = "Scott";
        int age = 20;

        // Use variables in output
        System.Console.Write("Hey ");
        System.Console.Write(studentName);
        System.Console.Write(", your age is ");
        System.Console.Write(age);

        System.Console.ReadKey();
    }
}
```

**Key Points:**
- Variables must be declared before use
- Assignment operator `=` assigns a value
- Variable names are case-sensitive

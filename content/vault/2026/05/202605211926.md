# C# Primitive Types

## The Core

C# primitive types are built-in value types that directly map to .NET System types. They are categorized into signed integers, unsigned integers, floating-point numbers, and other fundamental types.

| Category | Type | .NET Type | Size | Range |
|----------|------|-----------|------|-------|
| **Signed Integer** | `sbyte` | `SByte` | 8-bit | -128 to 127 |
| | `short` | `Int16` | 16-bit | -32,768 to 32,767 |
| | `int` | `Int32` | 32-bit | -2,147,483,648 to 2,147,483,647 |
| | `long` | `Int64` | 64-bit | ±9.2 × 10^18 |
| **Unsigned Integer** | `byte` | `Byte` | 8-bit | 0 to 255 |
| | `ushort` | `UInt16` | 16-bit | 0 to 65,535 |
| | `uint` | `UInt32` | 32-bit | 0 to 4,294,967,295 |
| | `ulong` | `UInt64` | 64-bit | 0 to 1.8 × 10^19 |
| **Floating-Point** | `float` | `Single` | 32-bit | ~6-9 digits precision |
| | `double` | `Double` | 64-bit | ~15-17 digits precision |
| | `decimal` | `Decimal` | 128-bit | 28-29 digits precision |
| **Other** | `char` | `Char` | 16-bit | Unicode character |
| | `bool` | `Boolean` | 8-bit | true/false |
| | `string` | `String` | Reference | Unicode text |

## Context & Details

**Type Constants and Default Values:**

```csharp
// MaxValue constants
sbyte a = sbyte.MaxValue;  // 127
byte d = byte.MaxValue;    // 255
short e = short.MaxValue;  // 32767
ushort f = ushort.MaxValue; // 65535
int g = int.MaxValue;      // 2147483647
uint h = uint.MaxValue;    // 4294967295
long i = long.MaxValue;    // 9223372036854775807
ulong j = ulong.MaxValue;  // 18446744073709551615
float k = float.MaxValue;  // 3.40282347E+38
double l = double.MaxValue; // 1.7976931348623157E+308
decimal m = decimal.MaxValue; // 79228162514264337593543950335

// Default values
sbyte c = default(sbyte);  // 0
bool p = default(bool);    // false
```

**Key Patterns:**
- Use `MaxValue` / `MinValue` for type bounds
- Use `default(T)` or declare without initialization for default values
- `int` and `double` are default choices for general use
- `decimal` for financial calculations requiring precision

# CSharp Operators Overview

## The Core

| Category | Operators | Description |
|----------|-----------|-------------|
| Arithmetic | `+ - * / %` | Basic math operations |
| Assignment | `+= -= *= /= %=` | Combined assignment |
| Increment/Decrement | `++ --` | Prefix/postfix modification |
| Comparison | `== != < > <= >=` | Return boolean results |
| Logical | `& && \|\| \| ! ^` | Boolean logic with/without short-circuit |
| String | `+` | Concatenation |
| Ternary | `? :` | Conditional expression |

**Operator Precedence**: `* / %` > `+ -` (use parentheses when unsure)

## Context & Details

**Arithmetic Operators:**
```csharp
decimal a = 10M, b = 3M;
decimal sum = a + b;      // 13
decimal diff = a - b;     // 7
decimal product = a * b;  // 30
decimal quotient = a / b; // 3.333...
decimal remainder = a % b; // 1
```

**Assignment Operators:**
```csharp
a += 20M;  // a = a + 20
a -= 20M;  // a = a - 20
a *= 3M;   // a = a * 3
a /= 3M;   // a = a / 3
a %= 3M;   // a = a % 3
```

**Increment/Decrement:**
```csharp
a = 10M;
System.Console.WriteLine(++a); // 11 (prefix: increment then use)
System.Console.WriteLine(a++); // 11 (postfix: use then increment)
System.Console.WriteLine(a);   // 12
```

**Comparison Operators:**
```csharp
bool isEqual = a == 10;   // equality
bool notEqual = a != 10;  // inequality
bool lessThan = a < 10;   // less than
bool greaterThan = a > 10; // greater than
bool lessOrEqual = a <= 10; // less or equal
bool greaterOrEqual = a >= 10; // greater or equal
```

**Logical Operators:**
```csharp
bool b1 = a == 10 & b == 10;    // AND (evaluates both)
bool b2 = a == 10 && b == 10;   // AND (short-circuit)
bool b3 = a == 10 | b == 10;    // OR (evaluates both)
bool b4 = a == 10 || b == 10;   // OR (short-circuit)
bool b5 = !(a == 10);           // NOT
bool b6 = a == 10 ^ b == 10;    // XOR
```

**String Concatenation:**
```csharp
string name = "Scott";
int age = 20;
string message = "Hey " + name + ", your age is " + age + ".";
// Output: Hey Scott, your age is 20.
```

**Ternary Operator:**
```csharp
string title = (age < 13) ? "Child" : (age >= 13 && age <= 19) ? "Teenager" : "Adult";
// Nested ternary for multiple conditions
```

**Operator Precedence Example:**
```csharp
double z = 10 + 4 * 30 / 10;  // 22 (multiplication/division first)
// 4 * 30 = 120, 120 / 10 = 12, 10 + 12 = 22
```

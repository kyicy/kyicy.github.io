# C# If-Else Statement for Conditional Logic

## The Core

| Component | Description |
|-----------|-------------|
| `if` condition | First condition to evaluate, executes block if true |
| `else if` chain | Additional conditions checked only if previous conditions are false |
| `else` | Default case when all conditions fail |
| Evaluation order | Sequential, stops at first true condition |
| `&&` operator | Logical AND, both conditions must be true |

## Context & Details

The if-else if-else chain executes conditions in order, stopping at the first true condition. This makes range checks efficient when ordered correctly.

**Example: Grade assignment based on marks**
```csharp
int marks = 45;
char gradeLetter;

if (marks >= 85)           // O grade: 85 and above
{
    gradeLetter = 'O';
}
else if (marks >= 60 && marks < 85)  // A grade: 60-84
{
    gradeLetter = 'A';
}
else if (marks >= 50 && marks < 60)  // B grade: 50-59
{
    gradeLetter = 'B';
}
else if (marks >= 35 && marks < 50)  // C grade: 35-49
{
    gradeLetter = 'C';
}
else                            // F grade: below 35
{
    gradeLetter = 'F';
}

System.Console.WriteLine(gradeLetter);  // Output: C
```

**Key Points:**
- Once a condition is true, subsequent conditions are skipped
- Use `>=` and `<` to avoid gaps or overlaps in ranges
- The final `else` handles all remaining cases
- Conditions are evaluated from top to bottom

# C# Switch Statement

## The Core

| Component         | Description                                 |
| ----------------- | ------------------------------------------- |
| `switch` keyword  | Starts the switch statement block           |
| Expression        | Value to evaluate (char, int, string, etc.) |
| `case` clauses    | Match specific values and execute code      |
| `break` statement | Exits the switch block after a case         |
| `default` clause  | Fallback when no cases match                |

## Context & Details

**Pattern:** Conditional branching based on a single expression value. Each case matches one specific value and executes its associated code block.

**Example - Grade Description:**
```csharp
char gradeLetter = 'A';
string gradeDescription;

switch (gradeLetter)
{
    case 'O': gradeDescription = "Outstanding"; break;
    case 'A': gradeDescription = "Excellent"; break;
    case 'B': gradeDescription = "Good"; break;
    case 'C': gradeDescription = "Average"; break;
    case 'F': gradeDescription = "Fail"; break;
    default: gradeDescription = "None"; break;  // Fallback
}

System.Console.WriteLine(gradeDescription);  // Output: Excellent
```

**Key Rules:**
- Each case requires `break` (or `goto`, `return`) to prevent fall-through
- `default` is optional but recommended for robustness
- Cases can be any constant expression
- Only one case block executes per switch evaluation

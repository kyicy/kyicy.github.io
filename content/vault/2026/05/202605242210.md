# C# Break Keyword

## The Core

| Keyword | Purpose | Scope |
|---------|---------|-------|
| `break` | Exit loop or switch immediately | Loops, switch statements |

**Effect:** Terminates the nearest enclosing loop or switch, skipping all remaining iterations.

## Context & Details

**Break from For Loop:**
```csharp
for (int i = 0; i < 10; i++)
{
    if (i == 5)
    {
        break;  // Exit loop when i equals 5
    }
    System.Console.Write(i + " ");
}
// Output: 0 1 2 3 4
```

**Key Points:**
- `break` only exits the innermost enclosing loop
- No further iterations are executed
- Code after the loop continues normally
- Used in for, while, do-while, foreach loops, and switch statements

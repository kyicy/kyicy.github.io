# C# continue Keyword

## The Core

| Keyword | Behavior |
|---------|----------|
| `continue` | Skip remaining code in current iteration and jump to next iteration |

## Context & Details

The `continue` statement immediately exits the current loop iteration and advances to the next iteration of the nearest enclosing loop.

**Example:**
```csharp
for (int i = 0; i < 10; i++)
{
    if (i == 6)
    {
        continue;  // Skip when i equals 6
    }
    System.Console.Write(i + " ");  // Output: 0 1 2 3 4 5 7 8 9
}
```

**Key points:**
- Works with `for`, `foreach`, `while`, and `do-while` loops
- Only affects the current iteration
- Does not terminate the loop entirely (unlike `break`)

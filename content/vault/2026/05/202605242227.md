# C# goto Statement with Labels

## The Core

| Concept | Description |
|---------|-------------|
| `goto` statement | Unconditional jump to a labeled statement in the same method |
| Label | Identifier followed by a colon (`:`) marking a jump target |
| Loop control | Alternative to traditional loops for creating iteration patterns |

## Context & Details

**Basic Pattern:**

```csharp
mylabel:  // Define a label
// Code here
i++;
if (i <= 5)
{
    goto mylabel;  // Jump back to label
}
```

**Example with output:**

```csharp
int i = 1;
System.Console.WriteLine("USA");  // Printed once
System.Console.WriteLine("UK");
System.Console.WriteLine("India");

mylabel:
    System.Console.WriteLine("France");  // Printed 5 times
    System.Console.WriteLine("Italy");
    System.Console.WriteLine("Iran");
    i++;
    if (i <= 5)
    {
        goto mylabel;  // Loop back
    }

System.Console.WriteLine("Nepal");  // Printed once after loop
System.Console.WriteLine("Dubai");
```

**Output:**
```
USA
UK
India
France
Italy
Iran
France
Italy
Iran
France
Italy
Iran
France
Italy
Iran
France
Italy
Iran
Nepal
Dubai
```

**Key Points:**
- Labels must be unique within their scope
- `goto` can jump forward or backward
- Generally discouraged in modern programming—prefer `for`, `while`, `foreach`
- Useful in some scenarios like breaking out of nested loops or implementing state machines
